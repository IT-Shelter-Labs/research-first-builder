# Research First Builder

**Помогает ИИ-агенту обосновать архитектуру реальными источниками до разработки.**

Don't build from vibes. Build from evidence.

Проект [IT Shelter](https://github.com/IT-Shelter-Labs). Репозиторий называется `research-first-builder`,
а установленный скилл вызывается как **`research-first-build`**. `rfb.py` — его вспомогательная программа.
Канал IT Shelter в [Telegram](https://t.me/+ihTcvubt-_BhZTQ6).

**Что такое скилл?** Это папка с инструкциями и вспомогательными файлами для ИИ-агента, который работает
с вашим проектом. Здесь инструкции задают порядок: изучить реальные аналоги, объяснить выбор и отказ
от лишних решений, составить план, написать код и проверить результат. Программа `rfb.py` проверяет
согласованность записей. Дополнительные серверы, аккаунт RFB и платная подписка RFB не нужны.

Простое решение **NO-PATTERN** допустимо. Популярность репозитория не доказывает пригодность его архитектуры.

**Предварительная версия:** [статус релиза и проверок](docs/RELEASE_STATUS.md).
[Полная документация на английском](README.md) · [Примеры](examples/README.md).

## Первый запрос

```text
$research-first-build Исследуй аналоги локального приёмника webhook и реализуй
минимальный вариант для одного процесса. Сначала реальные источники,
потом доказательства, решения Adopt/Reject, план, код и проверки.
Материалы сохраняй в docs/research-first/inbox.
```

Для исследования без кода добавьте: `research-only, quick depth; реализацию пока не начинай`.

## Установка в приложение

Из папки целевого проекта, если установлен Node **22.20+**:

```text
npx skills@1.7.0 add IT-Shelter-Labs/research-first-builder --skill research-first-build --agent codex --copy
```

Установка из GitHub проверена в чистом проекте без авторизации Git. Она не подтверждает полный запуск
модели во всех агентах; [точный статус](docs/COMPATIBILITY.md) указан отдельно.
Для установки копированием скачайте [архив скилла из релиза](https://github.com/IT-Shelter-Labs/research-first-builder/releases/tag/v0.1.0-rc1)
или используйте локальную копию репозитория.

Скопируйте всю папку `skills/research-first-build` в проект, с которым работает агент:

- Codex в приложении: `.agents/skills/research-first-build`.
- Claude Code: `.claude/skills/research-first-build`.
- Cursor/OpenCode: `.agents/skills/research-first-build`, пока beta.

Отдельный Codex CLI для этого не нужен. Откройте именно папку целевого проекта с `.agents/skills` в локальном режиме работы с кодом,
выберите скилл или вызовите `$research-first-build`. Если он не появился, перезапустите сессию/приложение.
Для выполнения проверок нужен Python 3.11+, для исследования — доступ агента к источникам и файлам.
Обычный чат без доступа к локальному проекту не сможет выполнить весь процесс.

Можно начать без установки, явно указав агенту путь к `skills/research-first-build/SKILL.md` и попросив прочитать
его и нужные ссылки. Это позволяет проверить работу скилла, даже если он ещё не появился в списке.

## Что вы получите

Результат: `RESEARCH.md`, `PLAN.md`, `VERIFICATION.md`, `evidence.json`, заметки источников и реальные
выводы проверок. Программа проверяет связи, полноту записей и соответствие результатов проверенной версии файлов.
Под «снимком» (`snapshot`) понимается идентификатор этой версии, включая изменения, ещё не попавшие
в коммит. Под записью проверки (`receipt`) — сохранённые результат, время и версия проверенных файлов.

Чтобы продолжить исследование, попросите агента использовать существующую папку результатов.
`resume` означает продолжение работы, а не значение `intent` в JSON. Когда вы разрешаете реализацию
плана `research-only`, агент меняет `intent` на `full` и повторно проверяет готовность плана.
Любая правка `RESEARCH.md` или `PLAN.md`, даже опечатка, требует повторной проверки плана перед завершением работы.

## Ограничения и статус

Учебные примеры и [полный тест в приложении](docs/acceptance/DESKTOP_BOOKMARKS.md) прошли. В этом тесте
агент читал файл скилла напрямую; выбор через встроенный список и полный запуск во всех агентах пока
не подтверждены. Сравнительный эксперимент ещё не выполнен. [Точный статус](docs/COMPATIBILITY.md).

Проверка согласованности не доказывает истинность источников, подлинность результатов тестов или
юридическую допустимость копирования чужого кода. Изучение источников и выполнение тестов остаются
работой агента и проверяющего. `rfb.py` не запускает команды из JSON и не обращается к сети.
Расходы на модель и инструменты вашего агента сохраняются.

Ветка `main` содержит исправления после первого релиза. Архивы `v0.1.0-rc1` сохраняют исходную версию.
