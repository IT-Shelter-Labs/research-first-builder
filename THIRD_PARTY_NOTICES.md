# Third-party study and dependencies

The MIT license covers this repository's original instructions, helper, templates, tests and educational implementations.
No third-party repository source code was copied into those implementations. Research notes paraphrase narrow findings
and link primary locations. A PATTERN_ONLY record is not a legal compatibility finding.

Examples inspect Zulip (Apache-2.0), Tinode server (GPL-3.0-only), hack.chat (declared MIT; license file retrieval
unavailable), adnanh/webhook (MIT), Svix (MIT), jq (MIT core; documentation rights separate), ripgrep (MIT OR Unlicense),
and primary Stripe/SQLite/Python/JSON Lines documentation. Exact revisions, scope, inspected/declared/missing status
and limitations are in each evidence.json. Unknown documentation rights remain unknown; no full documents are vendored.

The skills installer is optional external tooling, not bundled code. GitHub Actions are referenced by pinned commits
in CI. Pillow is used only to regenerate the original artifact-walkthrough GIF; it is not an installed skill dependency.
There are no redistributed runtime libraries, fonts or reference application assets in this package.
