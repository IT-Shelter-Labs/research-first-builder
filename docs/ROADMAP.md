# Roadmap

## Candidate to public 0.1

Complete normal native primary-host acceptance, run the hosted check matrix, review organization/author privacy,
and verify remote installation after publication. Run a declared-budget comparison and consenting pilot before
advertising measurable benefits. The [release status](RELEASE_STATUS.md) records incomplete gates explicitly.

## After real usage

- Reduce evidence authoring/review effort where pilot data shows friction; keep provenance visible.
- Add current native Cursor/OpenCode acceptance reports before upgrading their compatibility tier.
- Extend examples with a substantial feature inside an existing project and a real source contradiction.
- Consider a skill-only native plugin manifest only if users need that distribution route.
- Add narrow contract migrations when schema changes become necessary, preserving old artifacts.

Feature/architecture-specific commands can follow a strong core workflow. UI research and productionize suites
remain later scope. No backend, SaaS, mandatory MCP, source crawler or multi-agent orchestrator is planned for this MVP.
RepoLens remains a separate future project.

Proposed publication topics: `ai`, `coding-agents`, `agent-skills`, `claude-code`, `codex`,
`developer-tools`, `software-architecture`, `research`, `open-source`.
